# Minishell

A simple UNIX shell implemented in C as part of the 42/1337 curriculum, inspired by Bash.

## Features

* Command execution using `execve()`
* Input and output redirections (`<`, `>`, `>>`, `<<`)
* Exit status handling and propagation
* Environment variable management
* Pipes and command execution
* Signal handling and process management

## My Contribution

Focused on the **execution part** of the shell, including command execution, input/output redirections, process management, and handling exit statuses and return values.

## Technologies

* C
* UNIX / Linux
* System calls
* Processes and file descriptors
* Makefile

## Usage

```bash
make
./minishell
```

## Learning Outcomes

Gained practical experience with UNIX system calls, process execution, file descriptor management, redirections, and shell behavior.
